# M&E Pricing Platform — Implementation Plan

## Goal

Deliver a runnable local web platform that imports the six workbooks in `input/`, normalizes useful rows into a local operational database, prices a new/holdout BOQ with deterministic hybrid matching, exposes risky rows for review, and exports an Excel result with an audit sheet.

## Decisions

- **Runtime:** Python 3.12, FastAPI, server-rendered static HTML/CSS/JS.
- **Database:** SQLite for zero-setup local development, with canonical tables and SQL migration files designed to be portable to PostgreSQL.
- **Excel:** `openpyxl` for `.xlsx`, `xlrd` for legacy `.xls`; preserve raw source files and raw row JSON.
- **AI:** optional provider abstraction reading `CLAUDE_BASE_URL`, `CLAUDE_API_KEY`, and `CLAUDE_MODEL` from `.env`; deterministic parsing/matching remains the default and no price is ever generated by an LLM.
- **Search:** normalized token/technical-attribute retrieval in SQLite now; repository interfaces leave a path to PostgreSQL full-text/pgvector.
- **UI:** Vietnamese workflow: Dashboard → Data Hub/import → New quotation → pricing results/review → export.

## Delivery slices

1. Workbook inspector, classifier, header/column detector, row extraction, normalization, validation.
2. Canonical SQLite schema, migrations, import service and source/provenance storage.
3. Product/labor catalog matching, versioned material/labor pricing, confidence and review states.
4. Quotation API, review/correction API, export service and audit workbook.
5. Single-page enterprise UI for import, quotation, review and export.
6. Sample ingestion, holdout benchmark, regression/unit/integration tests, README and limitations.

## Acceptance checks

- All available sample files can be inspected; `.xls` and `.xlsx` both parse.
- Raw descriptions/provenance are retained.
- No applied price lacks a source.
- Ambiguous/missing matches become `REVIEW_REQUIRED`, `NO_MATCH`, or `NO_PRICE_FOUND`.
- Holdout benchmark excludes holdout prices from searchable knowledge.
- Export is a usable `.xlsx` with original row data plus an `AI Audit` sheet.
- Local run is documented and automated tests pass.
